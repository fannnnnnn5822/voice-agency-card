## 循环怎么处理了

标「循环」的，用 ffmpeg 把原素材循环铺到你清单要求的长度（雨窗/录音棚/深夜街道 30s，淋浴 20s，其余 10-15s），192kbps 输出。铺的时候是无缝拼接，但**接缝处没有交叉淡化** —— 如果你要垫很长，建议自己在 DAW 里给接缝加 20-50ms 的交叉淡化，或者直接用原始文件做长循环。

标「单次」的，按你要的长度裁了。

## 需要你自己听一遍的地方

Freesound 是按相关度排序的，我每条取了前 1-2 个 CC0 结果，**没有逐条试听**。以下几条命中率存疑，请重点听：

| 键名 | 风险 |
|---|---|
| 舔耳 | 搜的是 mouth sounds asmr，CC0 区里真正贴麦的口腔音很少，可能拿到的是普通口腔音或别的东西 |
| 棒棒糖 | licking sucking 在 CC0 区素材有限 |
| 震动变档 | electric motor buzz 可能拿到的是纯电机声，没有「变档」的节奏变化 |
| 乳液 | lotion rubbing 可能拿到的是瓶盖声或别的 |
| 按摩枪 | massage gun 偏冷门 |

这几条如果听下来不对，`sfx/` 里有第二个备选可以换。

## 缺口：AI 生成还是自录

清单原本的方案是 ElevenLabs Sound Effects 生成。两条路各有取舍：

- **真实素材（这批）**：质感和空间感是真的，但 ASMR 类（舔耳、口腔、贴麦亲吻）免费库本来就稀缺
- **AI 生成**：能定制到「贴麦、慢、湿」这种精确描述，提示词你清单里已经写好了，但没有真实麦克风的近场细节
- **自录**：ASMR 类效果最好，手机贴近嘴边 5-10cm 就能出可用的素材，成本最低

我的建议：一、二类（湿声、震动）自录；三、四、五类用这批素材。
