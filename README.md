# 声色事务所

SillyTavern 角色卡。你接手一家快倒闭的小配音事务所：面试新人、给她们取艺名、排练、录音、把作品挂到全服市场上卖。

- `card.json`：角色卡本体，导入酒馆即可。卡里带「自动更新角色卡」，有新版时会出现更新按钮。
- `dist/shacho.js`：社长室面板的完整代码。卡里的加载器按提交号从这里取，玩家能审到实际运行的代码。
- `changelog.md`：版本记录。
- `portraits/`、`sfx/`：面试头像和音效。

需要酒馆助手（JS-Slash-Runner）。语音用 Fish Audio 或 MiniMax，自己在社长室 ⚙ 里填 key。
